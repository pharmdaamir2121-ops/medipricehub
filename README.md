# MediPriceHub starter website

This is a static, AdSense-conscious starter site for a healthcare information and price-comparison business.

## Before launch
1. The site is configured for GitHub Pages at https://pharmdaamir2121-ops.github.io/medipricehub/. Update the base URL if the site later moves to a custom domain.
2. Replace placeholder contact emails.
3. Only publish independently verified prices and seller details; unverified guide tables have been removed.
4. Expand the starter health articles with original, well-researched content and appropriate references.
5. Add a real cookie/consent solution appropriate for the countries you serve before enabling advertising.
6. Add Google Search Console and analytics.
7. Have legal/medical content reviewed as appropriate for your jurisdiction.
8. Do not use the site to unlawfully sell or promote prescription/regulated medicines.

## Structure
- index.html: homepage
- medicine-prices.html: price-guide hub
- discounts.html: offers
- health-guides.html: education hub
- pharmacy-directory.html: verified listings template
- about.html, contact.html, privacy.html, disclaimer.html, terms.html, editorial-policy.html
- product price guides
- 30 starter SEO article pages
- assets/style.css and assets/site.js
